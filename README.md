# Create Blazor Polar and Radar Charts in Just 10 Minutes

## Overview

This sample demonstrates how to create Polar and Radar chart visualizations using the Syncfusion Blazor Chart component in a hosted Blazor WebAssembly application. The solution illustrates how to bind data to chart series, switch between Polar and Radar chart types, and configure commonly used chart elements such as legends, tooltips, and data labels. The sample provides a practical starting point for developers who need to visualize comparative, categorical, or performance-based datasets using circular chart representations.

The project uses a hosted Blazor WebAssembly architecture with separate Client, Server, and Shared projects and demonstrates chart rendering within a modern Blazor application.

## Key Features

- Demonstrates Syncfusion Blazor Polar Chart rendering.
- Demonstrates Syncfusion Blazor Radar Chart rendering.
- Shows how to bind data collections to chart series.
- Uses chart series configuration to display Polar and Radar visualizations.
- Demonstrates chart legends for category identification.
- Demonstrates chart data labels for displaying data values.
- Demonstrates chart tooltips for interactive data inspection.
- Shows how Polar and Radar charts can visualize category-based datasets.
- Implements chart examples within a hosted Blazor WebAssembly application structure.

## Prerequisites

- Visual Studio 2022 or Visual Studio Code
- .NET SDK compatible with the project's target framework

## How to Run the Project

**Visual Studio 2022**

1. Clone or download this repository.
2. Open the solution file `PolarAndRadarChart.sln`. 
3. Restore all NuGet packages.
4. Set the hosted application startup project if required.
5. Build the solution.
6. Run the application using `Ctrl+F5`.

**Visual Studio Code**

1. Open the repository folder in Visual Studio Code.
2. Open the integrated terminal.
3. Navigate to the repository root containing the solution and project files.

```bash
dotnet restore
dotnet run
```

4. Open the local application URL displayed after the application starts.
