# Create Blazor Polar and Radar Charts in Just 10 Minutes

## Project Overview
This project shows how to quickly get started with Polar and Radar charts in a Blazor Server application. It focuses on demonstrating core charting concepts such as rendering data series, configuring chart types, and enabling commonly used visualization features. The sample is designed to be simple and instructional, making it easy for developers to understand how Polar and Radar charts work within the Blazor framework.

The application uses Syncfusion Blazor Charts to display chart data visually and highlights best practices for setting up chart components in a Blazor Server environment.

## Features
- Polar chart implementation in a Blazor Server app
- Radar chart implementation using Syncfusion Blazor Charts
- Support for multiple plotting types
- Data markers for better data visibility
- Tooltip support for interactive data inspection

## Prerequisites
To run this project, ensure you have the following installed:
- Visual Studio 2022
- .NET SDK compatible with Blazor Server projects

## How to Run the Project
1. Check out this project to a local directory on your system.
2. Open the solution file using Visual Studio 2022.
3. Restore the required NuGet packages by rebuilding the solution.
4. Run the project using the Visual Studio debugger or Ctrl + F5.

## Usage
Once the application is running, the Polar and Radar charts will render automatically as part of the Blazor Server app. You can explore the visual elements such as data markers, tooltips, and different plotting styles directly in the UI.
